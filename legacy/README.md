# Legacy (first prototype)

This folder holds the first GiveChain prototype (ETH-based, one shared donation pool), written before the Phase 1 redesign. Hardhat does not compile or test anything here.

It is kept so the report can compare the first version with the redesign, and so the original work stays easy to find. The full history is also in git.

The new contracts in `contracts/` replace these, one by one, during Phase 2 (see `docs/PLAN.md`).
